# STIKR — генератор шрифтовых стикеров

Одностраничное веб-приложение: пользователь пишет текст, настраивает оформление
(шрифт, обводка, цвет, изгиб) и скачивает PNG с прозрачным фоном.

**Демо:** https://surzhikxv.github.io/stikr/

## Что внутри

- Весь проект — один файл `index.html`. Сборки, зависимостей и сервера нет.
- Изгиб текста — через SVG `<textPath>`, без сторонних библиотек.
- Экспорт PNG: шрифт скачивается и вшивается в SVG перед растеризацией, иначе
  в готовом файле буквы подменяются системным шрифтом. Разрешение втрое больше превью.
- Аккаунт, статус PRO и галерея — имитация на `localStorage`, привязана к браузеру.
  Реальной оплаты и базы пользователей нет, это предусмотрено техническим заданием.

## Отступление от ТЗ

В исходном списке из 14 шрифтов у 10 нет кириллических глифов — русский текст в них
подменялся системным шрифтом. По согласованию с заказчиком они заменены на аналоги
того же характера с поддержкой кириллицы. Группы и количество шрифтов сохранены,
подробности — в комментарии над массивом `FONTS` в коде.

## Запуск локально

Достаточно открыть `index.html` в браузере.
